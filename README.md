# Himachal Rest House Atlas

Interactive map of government rest houses in Himachal Pradesh:

- **303 HPPWD Rest Houses & Circuit Houses** — tariffs per HPPWD notification No. PWD-B-F0(12)/4/2025-270832 dated 30.01.2026 (Class A, B, C and Circuit Houses).
- **59 Jal Shakti Vibhag rest houses / inspection huts** — from the HimAtithi booking site.

Features: class filters, district list, nearby radius finder, details with tariffs, directions and Google Maps location, light/dark theme, phone and desktop layouts.

Single static page (`index.html`), no build step. Pin locations for small villages are approximate where marked "≈".
